# Crownfield Eye Hospital Database

This project contains SQL files for the Crownfield Eye Hospital database assignment.

## Software Required
- MySQL Server
- MySQL Workbench

## How to Run the Database
1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Download the SQL files from this GitHub repository.
4. Open the main database SQL script in MySQL Workbench.
5. Run the main script to create the database and tables.
6. Run the separate query files after the database has been created.
7. Run the procedure, trigger and security scripts as required.

## Database Tables
The database contains 10 tables: patient, speciality, clinician, clinic, appointment, diagnosis, medicine, prescription, prescription_item and follow_up.

## Project Files
The repository contains SQL scripts for the database implementation, queries and security features.
